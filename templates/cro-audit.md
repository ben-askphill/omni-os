Run a conversion rate audit of this Shopify store: $ARGUMENTS

1. Browse the store as a shopper on desktop and phone: home, a collection, a product, the cart and the start of checkout.
2. Pull the numbers you can reach (analytics, the store's own reports, session recordings) for the same funnel.
3. Rank the problems by expected impact, each with the evidence (a screenshot, a number) and a concrete fix.
4. Write the findings as a self-contained HTML report in the artifacts folder and sum up the top five in your reply.
5. Mark it as a draft for the client. Change nothing on the store.
