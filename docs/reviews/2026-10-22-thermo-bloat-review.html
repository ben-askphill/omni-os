Thermo review: bloat and dead code

22 October 2026 · baseline main @ 1007f0a (after #283 to #288 merged) · PR #289

A whole-repo pass with the thermo-nuclear code-quality skill, aimed at removing code nothing needs. Every cut was proven unused or redundant by grep across the server, Web UI, Mac app, MCP and tests, then by typecheck and the full test suites. Nothing touches auth, the /api token, the PR-author gate, the pinned browser MCP, validation, size caps or path checks.

The headline finding: the codebase is already lean. tsc --noUnusedLocals --noUnusedParameters found 3 unused names across every TS package, knip found 5 truly unreferenced exports, and no workspace has an unused dependency. The real bloat was duplicated helpers, props no caller passes, one late-binding hook layer, and dead Mac UI.

What was cut

Dead code, TypeScript

  • Unused imports addEvent (runner/queue.ts) and TextP (Transcript.tsx).
  • harnessFor in brand.tsx and the Codex protocol types RpcRequest, RpcResponse, CommandExecutionItem, AgentMessageItem: referenced nowhere.
  • MODELS in web api.ts, the .shimmer class and its keyframes in index.css.
  • config.codexBin and config.cursorBin: never read; the bin lookups read the env themselves.

Dead code, Mac app

  • Views and helpers nothing calls: Spinner, NewThreadScreen, artifactSymbol, omniGroup, pillPrimary, eight unused ThreadStyle status colors.
  • OmniKit methods with no caller: ReplyComposerModel.clearError, ChannelBrowser.claimSize.
  • OmniKit API only its own tests called: openThreadMarkdown, Attachment.thumbnailSize, dotIsHollow, isManual. Their 3 tests and 3 assertions went with them.

Duplicate helpers

  • parsePayload (api.ts and transcript/fold.ts) now lives once in format.ts.
  • optionId (FileMenu.tsx copy of SlashMenu.tsx) and TASK_END (Transcript.tsx copy of delegation.ts).
  • refusal() was defined four times in the runner; now once in runner/state.ts.
  • The Hermes adapter's sleep duplicated the client's.
  • Mac: Automation's private shortPath matched Format.shortPath (checked on /Users/x, /Users/x/, /Users//x and long paths); four views inlined Pasteboard.copy; the thumbnail frame repeated thumbnailBox.

Over-abstraction

  • Runner bind hooks. state.ts held throwing stubs that queue.ts and records.ts filled in at import time, so session.ts could call pump, reportToParent and endTasks without importing their owners. The targets are hoisted function declarations only called at runtime, and the import cycle already existed, so session.ts and records.ts now import them directly.
  • Brand components. OmniLogo had a mark variant and a live variant nobody rendered; it is now OmniWordmark. Loader lost label, OmniMark lost droplets, interactive, className and style, StaticMark lost ring and style, HarnessMark lost size and className. No caller passed any of them, so every rendered output is the same.

Stray files and stale docs

  • csrf-guard-webui.png at the repo root: a PR screenshot committed in #280, linked from nowhere.
  • apps/mac/NOTES.md: lines about NewThreadScreen, QuickComposer, recentChanged, ContentUnavailableView and placeholder screens described code that no longer exists.
