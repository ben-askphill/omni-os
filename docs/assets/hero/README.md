# README hero

`hero.html` is the source for `hero-light.png` and `hero-dark.png` at the top of the repo README. It is built from the "Omni for Mac" design system's Main window, DelegationCard and ReportCard, with neutral sample data.

Regenerate after editing `hero.html`, from the repo root:

```
npm i --no-save playwright && node docs/assets/hero/render.cjs
```
