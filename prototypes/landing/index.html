Each channel keeps its own browser with logins saved. It shows live next to the thread, and you can click in to take over for a login or a captcha.

How it works

One Node server on your Mac. Open it in the browser, the Mac app, or your phone.

Step 1

Add a channel per client

Point it at the repo and the store, pick a default agent, and add the secrets it needs from your Keychain.

Step 2

Ask in a thread or the Conductor

Start a thread yourself, or ask the Conductor and let it route the work to the right channel and role.

Step 3

Review what comes back

Reports, pages, pull requests and screenshots land in the thread. Reply from your desk or your phone.

Run it on your Mac today

Needs Node 24 and the Claude CLI signed in. Codex, Cursor and Hermes are optional; the model picker tells you how to set each one up.

Open the repo → 
# clone, then
$ npm install
$ npm run dev
# UI on http://localhost:4748
