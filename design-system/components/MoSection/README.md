A list section on the phone: a sentence-case caption, a quiet count and an optional action.

Captions are 12pt medium in fg-3, never all caps. Order on Activity: Needs you, Running, Done today. Leave empty sections out rather than showing an empty caption.

```jsx
<MoSection title="Running" count={4}>{rows}</MoSection>
```

On Expo, import the same name from `components/mobile/native` (copied into `apps/ios/src/ds/`).
