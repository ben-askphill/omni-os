Side panel column with surface-tray sections.

```jsx
<Panel title="Channel"><PanelSection label="Automations" meta="4">…</PanelSection></Panel>
```

Slides in and settles (500ms).

Resizable by default: drag the left edge, double-click to reset, arrow keys when focused. Width persists (`storageKey`). Pass `width` to control it, `resizable={false}` to lock it.
