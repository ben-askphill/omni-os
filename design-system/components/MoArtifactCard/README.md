An artifact in the thread: a white peek of the page on its surface card, its name in mono, and maximize to open it full screen.

Pass a snapshot of the page as `image`. On Expo you can render a non-interactive WebView in the peek instead. `live` adds the running glyph while the agent is still writing it.

```jsx
<MoArtifactCard name="funnel-before-after.html" sub="Funnel, 7 days before and after" onPress={openArtifact} />
```

On Expo, import the same name from `components/mobile/native` (copied into `apps/ios/src/ds/`).
