Ask-in-place confirm with an undo fuse — the default way to take a decision a thread is waiting on.

```jsx
<InlineConfirm label="Pause WEEKEND15" icon="pause" confirmLabel="Pause until #812" doneLabel="Paused" undoMs={4000} onConfirm={pause} />
```

needs=true fills the confirm half vermilion. Without undoMs it confirms immediately.
