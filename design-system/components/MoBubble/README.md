Your message in a thread: a right-aligned surface-2 bubble with who sent it above.

Agent prose runs full width at 15/1.6 with no bubble; only your messages get one. `sending` fades the bubble while it is on its way. `failed` keeps it on screen and puts the reason and the next step in the caption ("Not sent · Retry or Edit").

```jsx
<MoBubble caption="Delegated by the Conductor · T-4F2A">Find what changed in checkout.</MoBubble>
```

On Expo, import the same name from `components/mobile/native` (copied into `apps/ios/src/ds/`).
