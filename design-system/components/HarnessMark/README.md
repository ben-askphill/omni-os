Harness mark for a thread: the vendor's own monochrome logo (Claude, OpenAI for Codex, Cursor) in a soft disc, optionally with its name.

```jsx
<HarnessMark harness="codex" withLabel />
<HarnessLogo harness="claude-code" size={14} />
```

size md | lg. Logos come from Simple Icons (assets/harness/*.svg), rendered in currentColor. Never redraw, recolor with a status pop, or modify them.
